# Session: AppKit 0.89 upgrade and MCP transport plan

**Date:** 2026-10-30  
**Branch:** `mg-genie-appkit-0.89-upgrade`

## Problems

1. AppKit was pinned at 0.38.1 (latest 0.89.0); MLflow tracing peer `@mlflow/core` missing.
2. `package-lock.json` on `main` was out of sync with `package.json`: `npm ci` failed with `EUSAGE` (lockfile had `@opentelemetry/instrumentation@0.208.0`, manifest asked for `^0.57`).
3. MCP transport work (2025-11-25 spec) had an accepted plan but no execution plan; nothing implemented.

## Root causes

* Lockfile drift from earlier manual installs on the old repo.
* App OpenTelemetry pins (1.30 / 0.57) were two majors behind what AppKit 0.89 uses (2.8 / 0.219), so `npm install` reports an `@opentelemetry/core` peer conflict unless forced.
